# Aparat Intelligence — تحلیل هوشمند ویدیوهای آپارات

**نسخه:** ۲.۰.۰ — مهار Hermes (skill) — **زبان پیش‌فرض خروجی: فارسی**

این ابزار یک ویدیوی آپارات را به یک بسته مطالعاتی کامل تبدیل می‌کند:

- پیاده‌سازی متن گفتار فارسی (و انگلیسی/ترکیبی) با **مهر زمانی** `[HH:MM:SS]`
- خلاصه اجرایی و مفصل، نکات اصلی، حقایق کلیدی، نتیجه‌گیری‌ها
- استخراج موضوعات و **فصل‌بندی خودکار** با timestamp
- پرسش و پاسخ محتوایی با ارجاع به مهر زمانی و تفکیک «گفته‌شده» از «استنتاج»
- جزوه مطالعاتی، واژه‌نامه، فرمول‌ها و مثال‌ها
- تولید **آزمون** (چندگزینه‌ای + کوتاه‌پاسخ) و **فلش‌کارت**
- **تحلیل تصویری**: اسلایدها، نمودارها، متن روی تصویر (OCR) و رویدادهای بصری
- **مقایسه چند ویدیو** با حفظ منبع هر ادعا
- گزارش‌های Markdown / JSON، همه محلی (local)

**معماری جدید (۲.۰):** این مهار دیگر از هیچ ارائه‌دهنده خارجی هوش مصنوعی
(OpenRouter، Groq، Gemini) استفاده نمی‌کند. تمام استدلال هوش مصنوعی توسط
**مدل فعال هرمس** در مکالمه انجام می‌شود. اسکریپت‌ها فقط پردازش محلی رسانه
(دانلود، استخراج صوت، قطعه‌بندی، استخراج فریم) را انجام می‌دهند. هیچ کلید
API لازم نیست.

## نصب

این مهار در مسیر زیر نصب شده است (مهارهای محلی کاربر):

```
~/.hermes/skills/media/aparat-intelligence/
```

نیازمندی‌های سیستمی:

- Python 3.11+ (فقط کتابخانه استاندارد)
- `ffmpeg` و `ffprobe` (استخراج صوت و فریم)
- `yt-dlp` (فراداده و دانلود از آپارات)

```bash
# بررسی نیازمندی‌ها
ffmpeg -version && yt-dlp --version && python3 --version

# اجرای تست‌ها
python3 -m unittest discover -s tests -p "test_*.py"
```

## نحوه استفاده

### خط لوله رسانه (اجرای اسکریپت)

```bash
SKILL=~/.hermes/skills/media/aparat-intelligence

# خط لوله کامل: فراداده، دانلود، صوت، قطعه‌بندی، فریم، قالب گزارش
python3 $SKILL/scripts/main.py analyze "https://www.aparat.com/v/VIDEO_ID"

# مراحل جداگانه
python3 $SKILL/scripts/main.py metadata "URL"     # فقط فراداده
python3 $SKILL/scripts/main.py download "URL" DIR # دانلود ویدیو
python3 $SKILL/scripts/main.py audio "URL" DIR    # دانلود + استخراج صوت
python3 $SKILL/scripts/main.py chunks AUDIO DIR   # قطعه‌بندی صوت
python3 $SKILL/scripts/main.py frames "URL" DIR   # استخراج فریم‌های کلیدی

# مدیریت کش
python3 $SKILL/scripts/main.py cache list
python3 $SKILL/scripts/main.py cache clear
python3 $SKILL/scripts/main.py cache size
```

### تحلیل هوش مصنوعی (توسط مدل فعال هرمس)

اسکریپت‌ها تحلیل هوش مصنوعی انجام نمی‌دهند. مدل فعال هرمس در مکالمه:

| tarea | نحوه انجام |
|-------|-----------|
| پیاده‌سازی متن | ابزار STT هرمس (اگر مدل صوت پشتیبانی کند) |
| تحلیل تصویری | ابزار `vision_analyze` روی مسیر فریم‌ها (اگر مدل تصویر پشتیبانی کند) |
| خلاصه، موضوعات، Q&A | استدلال مدل روی متن پیاده‌سازی شده |
| جزوه، آزمون، فلش‌کارت | استدلال مدل روی متن پیاده‌سازی شده |
| مقایسه ویدیوها | استدلال مدل روی چند transcript |

مدل برای هر خروجی هوش مصنوعی باید **به مهر زمانی `[HH:MM:SS]` ارجاع دهد** و
**حقایق صریح را از استنتاج‌های مدل تفکیک کند**.

**دعوت از داخل هرمس:** زمانی که یک URL آپارات به کاربر می‌دهید، مهار به
صورت خودکار فعال می‌شود. برای فراخوانی مستقیم از عبارتی مانند
«این ویدیوی آپارات را تحلیل کن: <URL>» استفاده کنید.

### خروجی

هر ویدیو در فضای کار خودش:

```
~/.local/share/aparat-intelligence/output/<video_id>/
    metadata.json  transcript.json  transcript.md  (مدل تولید می‌کند)
    visual_analysis.json  frames.json
    summary.md  study_notes.md  quiz.md  flashcards.md  report.md
```

تمام مراحل رسانه (فراداده، صوت، فریم) در `~/.cache/aparat-intelligence/`
کش می‌شوند؛ اجرای interrupted با اجرای مجدد ادامه می‌یابد.

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| `could not retrieve metadata` | ویدیو حذف/خصوصی است، یا شبکه به آپارات دسترسی ندارد |
| `ffmpeg not found` | `sudo pacman -S ffmpeg` (آرچ) یا نصب از مخزن توزیع |
| مدل صوت را پشتیبانی نمی‌کند | STT محلی هرمس را پیکربندی کنید یا محدودیت را گزارش دهید |
| مدل تصویر را پشتیبانی نمی‌کند | فریم‌ها استخراج می‌شوند ولی تحلیل تصویری ممکن نیست |

جزئیات بیشتر: `references/troubleshooting.md`.

## محدودیت‌های فعلی

1. **این ماشین به آپارات دسترسی ندارد** — اتصال به تمام دامنه‌های ایرانی
   (از جمله `aparat.com`) توسط شبکه reset می‌شود. تست زنده نیازمند شبکه‌ای
   با دسترسی به آپارات است. تمام تست‌های خودکار آفلاین و با mock انجام
   شده‌اند و خط لوله end-to-end ویدیوی آزمایشی ffmpeg را پردازش می‌کند.
2. **مدل فعال متن‌ONLY است** — `upstage/solar-mini4:free` ورودی صوت/تصویر
   ندارد. پیاده‌سازی متن نیازمند STT محلی هرمس است؛ تحلیل تصویری نیازمند
   مدل با قابلیت تصویر است. مهار این محدودیت‌ها را گزارش می‌دهد، نه اینکه
   ارائه‌دهنده دیگری را مخفیانه معرفی کند.
3. تشخیص زبان خودکار بر اساس نسبت حروف فارسی/انگلیسی است (اکتشافی).
